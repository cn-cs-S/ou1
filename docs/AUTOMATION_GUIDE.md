# AI 自动化接管说明

## 当前可执行范围

当前版本对每个**本地测试账户**提供独立自动化开关。启用后，每 15 秒使用 OKX 真实公共市场行情进行一次评估，并在对应测试账户中模拟执行：

- 现货：买入/加仓、卖出/减仓、卖出清仓
- 永续：做多/加多、做空/加空、减仓、平仓
- 已有仓位：包括通过界面手动加入的测试仓位，均可进入自动复核

真实账户现在是只读估值账户。页面不会向 OKX 提交真实订单；未来接入交易权限 API 时，应增加单独授权、额度上限和停机保护后再开放真实执行。

## 每账户独立控制

在“所有账户总览”中，每个测试账户都有自己的 `AI 自动接管` 开关和 `运行` 按钮。开启某一个账户不会影响其他账户。每个账户保存独立的：

- 是否启用自动化
- 最近一次执行时间和下一次评估时间
- 当前策略参数
- 最近的操作与判断原因

服务重启后自动化默认关闭，需要重新启用，以防无人值守时误执行。

## AI 执行链路

系统按以下顺序决策：

1. 获取真实价格、K 线、资金费率、持仓量、盘口与最近主动成交。
2. 使用交易计划生成逻辑构建候选组合，仅在账户可用资金范围内配置新仓。
3. 对永续同时计算做多与做空方案，使用入场时机、风险分、资金费用和资金异动方向选择更优侧。
4. 对账户已有仓位单独复核，即使该币种不在新候选池中，也会检查止盈止损和强反向信号。
5. 经过仓位上限、可用资金、交易品种真实可用性与杠杆档位限制后，才写入测试账户。

## 触发动作

| 条件 | 自动动作 |
| --- | --- |
| 浮盈达到目标收益率 | 平仓止盈 |
| 浮亏达到最大回撤阈值 | 平仓止损 |
| 当前配置明显高于目标配置 | 减仓 25% |
| 永续多空对照与高置信资金异动强烈反向 | 平仓 |
| 永续多空对照确认反向但未达到强异动 | 减仓 25% |
| 已有方向再次被确认且未达到单币上限 | 按设置允许时加仓 |
| 新候选达到入场条件且资金充足 | 现货买入，或永续做多/做空 |

## 可配置风控

在 AI 组合计划的“设置”中可以控制：

- `目标收益 %`：达到后自动止盈平仓
- `最大回撤 %`：达到后自动止损平仓
- `产品倾向`：仅现货、仅合约或两者均可推荐
- `自动管理已有仓位`：是否把手动测试仓位交给 AI 复核
- `允许 AI 自动开立新仓位`
- `允许已持仓方向确认后自动加仓`
- `每轮最多动作`：限制一次评估能够改变的仓位数量
- `单币配置上限`：限制单一标的占用资金

## 重要限制

- 测试盈亏、手续费、资金费率和强平价均依据公开行情在本地估算，用于验证策略链路，不等于交易所最终结算结果。
- 资金异动判读只能识别公开数据的同向模式，不能确认真实操盘主体。
- 自动化输出为策略执行测试，不构成投资建议；真实资金交易应由用户独立评估并承担风险。
